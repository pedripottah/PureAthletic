# Archived Next.js implementation

This directory contains the original Next.js 14 / React 18 prototype that was
replaced by the vanilla HTML, CSS, and JavaScript implementation in the project
root.

To run this archived version independently:

```bash
npm install
npm run dev
```

Its original source entry points are:

- `app/layout.js`
- `app/page.js`
- `app/globals.css`

The `.next` directory in the repository root is an ignored build cache, not
application source.
